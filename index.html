Lock files so only your key opens them

Sealkey locks files in your browser with a 6-word key. Send the file one way and the key another.

  • Nothing is uploaded. Files stay on your device.
  • Only someone with the 6-word key can open them.

How to share safely
  1. Send the locked file one way, such as email or Google Drive.
  2. Send the key a different way, such as a message, a call or in person.
  3. Keep a copy of the key. If it's lost, nobody can open the file, including us.
About Sealkey

Everything happens in your browser. Files and keys never reach a server, and the page is blocked from sending data anywhere.

Each file is locked with XChaCha20-Poly1305 using a key stretched with Argon2id, through the libsodium library. Every part of the file is checked when it's opened, so any change is caught.

Sealkey can't protect you from

  • A hacked phone or computer
  • Someone who gets both the file and the key
  • A changed version of this website
  • A lost key. Nobody can recover the file.
